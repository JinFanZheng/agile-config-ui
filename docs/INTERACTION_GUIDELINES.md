# 交互规范（INTERACTION GUIDELINES）

> 适用范围：本前端全部页面与组件。新交互组件/页面实现前必读；评审时逐条对照。
> 依据：handoff §7.1（动效约束）、§8（UX 要求）、§0（可控原则）+ ITER-03 验收反馈（2026-09-04）。
> 本文档由 AGENTS.md 红线引用；违反即视为实现缺陷。

## 1. 动效

- 只做 **120–160ms ease-out 微过渡**；进入动画优先（淡入/微位移/微缩放 ≤150ms），退出可瞬时（避免卸载等待）
- 预置动画类（`src/index.css`）：`anim-overlay`（遮罩淡入 120ms）、`anim-modal`（弹窗 150ms 上浮+缩放）、`anim-menu`（菜单 130ms）、`anim-drawer`（抽屉 150ms 滑入）、`anim-toast`（150ms）
- **必须尊重系统"减少动态"**：`prefers-reduced-motion: reduce` 时全局降级（已内置，勿绕过）
- 禁止：弹跳、循环、视差、>200ms 的任何交互动效

## 2. 危险操作（§0 可控）

- **不可逆/影响面大的操作必须二次确认**（ConfirmDialog）：删除、回滚、客户端下线/强制重载、清缓存、重置他人密码等
- 确认弹窗规范：danger 语义色；正文**明示后果**（影响什么、是否可恢复）；确认按钮**重复动作动词**（"删除"而非"确定"）；Esc/遮罩/取消均可退出；提交期间禁用按钮
- 危险度再升级的场景（如删除带发布历史的应用）可要求**输入标识确认**（需用户拍板才加，避免处处设卡）
- 前端确认只是防误触层，真正的防线是服务端权限（ITER-07）

## 3. 脏表单保护（防丢数据）

- 表单弹窗 **isDirty 时，Esc / 遮罩 / X / 取消 一律先弹"放弃未保存的修改？"确认**（`useDirtyGuard`），确认放弃才关闭
- 保存成功后的关闭**直接关闭**（绕过守卫）
- 所有新表单弹窗（配置编辑、用户/角色编辑等）必须接入 `useDirtyGuard`

## 4. 操作反馈

- **变更类操作（创建/保存/删除/启停/发布/回滚）成功或失败必须有 Toast**（`toast.success/error`，2.6s 自动消失，最多同屏 3 条）；错误 Toast 显示服务端 message
- 就地操作（复制）用**内联反馈**（CopyButton 的 ✓），不用 Toast
- 列表刷新不构成反馈；按钮 pending 时禁用 + Spinner；提交中禁止重复触发

## 5. 空态与无结果（必须区分）

- **空态**（无数据）：引导创建（"还没有应用，创建第一个"）
- **无结果**（有过滤条件但筛空）："没有匹配的…" + **清除筛选**快捷操作
- 异步选项列表加载中显示"加载中…"，**不得**把加载态误显示为空态

## 6. 键盘与焦点

- Esc 关闭**最顶层浮层**（层级：Toast 不响应 > 嵌套确认 > 弹窗 > 抽屉 > 菜单）
- Enter 提交表单；弹窗确认按钮 autofocus
- 表格行内操作支持 Tab 聚焦（原生 button，勿用 div 做可点击元素）

## 6.5 面包屑与层级导航

- **≥2 级页面必须显示面包屑**（内容区顶部，替代大标题）；一级导航页（概览/应用/节点…）**不显示**（一层导航挂面包屑是噪音）
- 祖先段可点击（muted → hover 前景色 + 下划线）；当前段不可点、font-medium；AppId/键名等代码性质文本用等宽字体
- 深层钻取页（版本详情、节点客户端等）沿用同一组件，面包屑随路由 meta 生成

## 7. 列表行为

- 搜索输入防抖 300ms；清空关键词 = 清除过滤
- **删除当前页最后一条自动回退一页**，不得出现空页
- **创建成功后清除激活的过滤词**（含分组/环境筛选），避免新建实体被残留过滤器隐藏造成"创建失败"错觉（冒烟 ISSUE-001，2026-09-07）
- 加载用骨架屏（整表至少 4 行）；失败给重试按钮；轮询页面离开即停（TanStack Query 自动）

## 8. 主题与令牌

- 动画时长、阴影、圆角、颜色一律走令牌（`src/index.css`），禁止在组件里硬编码 hex/rgba/时长
- 环境语义色与状态语义色在任何主题下不得变（handoff §7.1 不变量）
