# 使用指南（管理员向）

> 面向 AgileConfig 管理台的使用者。部署见 [README](../README.md)；客户端接入见管理台内「接入指南」页或站点根 `/llms-full.txt`。

## 1. 首次进入

- 浏览器打开部署地址（如 <http://localhost:5173>）。实例首次使用会引导设置 admin 密码；之后用密码登录。
- 配置了 SSO 的实例会在登录页显示「SSO 登录」按钮（文案由服务端可配），点击后跳企业身份源，登录自动回到管理台。

## 2. 三个核心概念

| 概念 | 说明 |
| --- | --- |
| **应用** | 配置的归属单位，靠 AppId + Secret 供客户端连接。Secret 在新建/编辑应用时自行填写（服务端不自动生成，留空客户端连不上） |
| **环境** | 配置的第一维度（DEV / TEST / PROD 等）。顶栏切换器全局生效，各环境独立拥有配置集、待发布状态与发布历史 |
| **待发布 → 发布 → 回滚** | 改动保存后只是「待发布」，必须**发布**才对客户端生效（WebSocket 推送，约 1 秒）；每次发布生成版本快照，可任选两版对比、可回滚到历史版本 |

## 3. 最常走的路径：改一个配置并生效

1. 顶栏确认**环境**正确（如 DEV）；
2. 「应用」页进入目标应用 → 配置页（表格 / KV / JSON 三种视图任选）；
3. 改动保存 → 顶部出现**待发布计数**（新增/修改/删除三色）；
4. 点发布 → 强制 diff 预览，确认后填写发布说明 → 发布；
5. 客户端约 1 秒自动加载新值（无需重启）；在「发布历史」里可查看每个版本、双版本对比、回滚。

批量改动建议用 KV / JSON 视图；JSON 视图保存默认**补丁模式**（只动提交过的键）——全量模式会把没提交的键标记「待发布删除」，属危险操作。

## 4. 顶栏与侧栏

- **环境切换器**：全局生效，所有配置相关页面跟随；
- **主题切换器**：十套主题（浅色 5 + 深色 5）+「跟随系统」，与「设置」页双向同步；
- **侧栏**：概览 / 配置管理（应用、发布历史）/ 运维监控（客户端、节点、服务注册、日志）/ 权限管理（按你的权限显示）/ 接入指南、设置；桌面端可折叠为图标栏。

## 5. 设置中心（/settings）

浏览器本地个性化，即时生效、不落服务端：主题（含跟随系统的深浅映射自定义）、界面字号、编辑器字号、配置页默认视图、登录后打开页面、列表每页条数、编辑器自动换行、界面动效。

## 6. 运维视角

- **客户端**：在线实例一览（按节点聚合）；节点未注册时看不到实例属正常（见接入指南坑位）；
- **节点**：服务端节点管理、在线客户端数、远程重载；
- **服务注册**：SDK 注册上来的服务实例与健康状态；
- **系统日志**：操作审计。

## 7. 权限

按角色分配权限码，无权限的入口与按钮**直接不显示**（fail-closed）；新 SSO 用户默认 Operator 角色。

## 8. 常见问题

- **改了配置客户端没变？** 还没发布。看顶部待发布徽标。
- **客户端列表看不到我的实例？** 客户端列表按在线节点聚合，节点探活约 30 秒；且 Nodes 地址必须是客户端进程可达的地址（Docker 部署注意容器网络视角）。
- **对比视图在手机上？** 窄屏自动切单栏 inline 模式。
- **应用更新后旧标签页白屏/报错？** 已内置自动恢复（自动刷新一次加载新版本）。
- **想接新系统？** 把 `/llms-full.txt` 交给对方的 AI 编码助手，或按管理台「接入指南」六节照做。

更多实测坑位（JSON 扁平键、字面量归一化、isPatch 全量语义等）见管理台「接入指南」第 5 节。
