# ITER-16 侧栏导航分组

> 状态：验收中（EVIDENCE_READY，2026-09-08 实现与全量验证绿，等待用户验收）。
> 变更分类：小改（AppLayout 导航结构 + strings；不动路由与权限逻辑）。
> 前置：ITER-09/10/12（侧栏现有 11 入口）。

## 1. 评估结论

11 个入口的扁平列表已达扫描负担边缘；但本产品是紧凑运维台（w-48、text-xs 行高），只做**一层分组标签**（复用主题切换器定下的 10px 弱化标签样式，视觉语言一致），不做多级折叠。

## 2. 分组方案

| 组 | 项 | 权限过滤行为 |
| --- | --- | --- |
| （置顶不分组） | 概览 | 恒显 |
| 配置管理 | 应用、发布历史 | 组内逐项过滤 |
| 运维监控 | 客户端、节点、服务注册、系统日志 | 组内逐项过滤 |
| 权限管理 | 用户、角色 | 操作员无权时整组隐藏 |
| （底部不分组） | 接入指南、设置 | 恒显 |

规则：权限过滤后组内可见项为 0 → 整组（含标签）隐藏；移动端抽屉同结构。
